# Глоссарий QA Automation (Мой личный словарь)
## Модуль 0. Стартовая площадка
### Буква A
- **Automation** [о-то-мэй-шн] — «автоматизация». Замена ручного труда программой. (М0-01)
- **Agile** Гибкий подход к разработке, выкатка готового маиермла по спринтам
### Буква B
BVA (Boundary Value Analysis) - Анализ граничных значений
### Буква C
- **Commit** [коммит] — «фиксация». Сохранённая точка в истории Git. (М0-05)
- **CP** (copy) — команда терминала для копирования файлов. (М0-03)
- **checkout** - вернуть файл к последнему коммиту
- **Callback** -это функция, которую мы передаём внутрь другой функции как аргумент
### Буква D
- **diff** - вывод изменения в файле
- **Decision Table** таблица решений. Способ описать сложную бизнес-
логику, где результат зависит от комбинации нескольких условий
- **Data Type** «тип данных»
- **Destructuring** Синтаксис для извлечения элементов массива или свойств объекта в переменные одной строкой.
### Буква E
- **E2E-тесты** Сквозное тестирование. Имитация реального пользователя
- **ECP (Equivalence Class Partitioning)** Разбиение на классы эквивалентности
### Буква F
- **Functional Testing** Работает ли кнопка так, как написано в ТЗ
- **.forEach()** Выполнение действия для каждого элемента, ничего не возвращая (возвращает undefined)
### Буква G
- **Git** [гит] — система контроля версий. (М0-05)
- **GitHub** [гит-хаб] — облачная платформа для хранения Git-репозиториев. (М0-06)
- **Glossary** [глос-са-рий] — словарь терминов. (М0-07)
### Буква I
- **Integration-тесты** Проверка того, как компоненты работают вместе
- **.includes** возвращает true, если подстрока найдена.
- **Оператор "typeof"** возвращает строку с названием типа переменной
### Буква K
- **Kanban** To Do (Надо сделать), In Progress (В работе), Done
(Сделано). Задачи (стикеры) двигаются слева направо
### Буква L
- **log** - проверка всех комитов
### Буква M
- **Markdown** [марк-даун] — язык разметки текста (заголовки, списки). (М0-02)
- **MV** (move) — команда терминала для перемещения или переименования файлов. (М0-03)
* #### **Мутирующие методы (Mutating)**
    * - push() — добавляет элемент в конец массива.
    * - pop() — удаляет последний элемент из массива.
    * - unshift() — добавляет элемент в самое начало массива.
    * - shift() — удаляет первый элемент массива.
    * - sort() — сортирует массив на месте (коварная ловушка: меняет порядок элементов
    прямо в оригинале!).
    * - reverse() — переворачивает массив задом наперёд на месте.
- **Map** коллекция пар «ключ-значение» в Map ключом может быть любой тип данных (число, строка, булево значение и даже другой объект)
    * - new Map<KeyType,ValueType>() Создание словаря.указываем для TypeScript тип ключа и тип значения
    * - .set(key, value) Добавить или обновить пару «ключ-значение»
    * - .get(key) Получить значение по ключу (если ключа нет, вернёт undefined)
    * - .has(key) Проверить, существует ли такой ключ (возвращает boolean)
    * - .delete(key) Удалить пару по ключу.
    * - .size Количество записей в словаре (Подобие .length)
### Буква N
- **Node.js** [ноуд джей-эс] — среда выполнения JavaScript вне браузера. (М0-04)
- **NPM** [э-н-пи-эм] — Node Package Manager, менеджер пакетов. (М0-04)
- **Non-functional Testing** Как быстро работает или «Удобно ли пользоваться?»
* #### **Не мутирующие методы (Non-mutating / Immutable)** Они вообще не трогают оригинальный массив
    * - Главная шестёрка: map(), filter(), find(), some(), every(), reduce() - копилка.
    * - Современный стандарт toSorted() (безопасная сортировка без мутации оригинала) и toReversed().
### Буква P
- **PWD** (print working directory) — команда терминала, показывающая текущую папку. (М0-01)
- **push** - отправить в облако
- **pull** - взять из облака
- **Pairwise Testing** - «попарное тестирование»
### Буква R
- **Repository** [репозиторий] — хранилище кода и его истории. (М0-05)
- **RM** (remove) — команда терминала для удаления. (М0-03)
- **Regression Testing** разработчик
починил кнопку «Вход», тест проверяет, что кнопка «Выход» всё ещё работает.
- **Reference Type** Ссылочный типтип данных, который хранит не само значение, а ссылку (адрес) на место в памяти, где это значение лежит
### Буква S
- **SSH** [эс-эс-эйч] — безопасный протокол для связи с GitHub. (М0-06)
- **SDLC** (Software Development Life Cycle) Жизненный цикл разработки
программного обеспечения
- **STLC** (Software Testing Life Cycle) Жизненный цикл тестирования
- **Scrum** Спринты (обычно 2 недели)
- **Smoke Testing** быстрый тест после сборки
- **Sanity Testing** Узкое тестирование конкретной фичи после её исправления
- **setTimeout(функция, миллисекунды) — выполняет код с задержкой**
- **Spread Operator** ... это способ безопасно скопировать массив или объект, создав новый участок памяти
- **Set (Множество)** коллекция значений, в которой каждый элемент может встречаться только один раз
    * - **new Set(array) Создание множества**
    * - **.add(value) Добавить элемент в Set.**
    * - **.has(value) Мгновенно проверить наличие элемента (возвращает true или false).**
    * - **.delete(value) Удалить конкретный элемент.**
    * - **.clear()**
    * - **.size Количество элементов в Set ( у массива .length, а у коллекций Set и Map — .size без круглых скобок!)**
### Буква T
- **Touch** [тач] — команда терминала для создания пустого файла. (М0-03)
- **Test Pyramid** много быстрых тестов внизу, мало медленных тестов наверху
- **Test Design** процесс
превращения требований в набор эффективных и достаточных тестовых сценариев
### Буква U
- **Unit-тесты** Модульные тесты
### Буква V
- **Variable** (Переменная) «изменяемая»
