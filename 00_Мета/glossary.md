# Глоссарий QA Automation (Мой личный словарь)
## Модуль 0. Стартовая площадка
### Буква A
- **Automation** [о-то-мэй-шн] — «автоматизация». Замена ручного труда программой. (М0-01)
- **Agile** Гибкий подход к разработке, выкатка готового маиермла по спринтам
### Буква B
BVA (Boundary Value Analysis) - Анализ граничных значений
### Буква C
- **Commit** [коммит] — «фиксация». Сохранённая точка в истории Git. (М0-05)
- **CP** (copy) — команда терминала для копирования файлов. (М0-03)
- **checkout** - вернуть файл к последнему коммиту
### Буква D
- **diff** - вывод изменения в файле
### Буква E
- **E2E-тесты** Сквозное тестирование. Имитация реального пользователя
- **ECP (Equivalence Class Partitioning)** Разбиение на классы эквивалентности
### Буква F
- **Functional Testing** Работает ли кнопка так, как написано в ТЗ
### Буква G
- **Git** [гит] — система контроля версий. (М0-05)
- **GitHub** [гит-хаб] — облачная платформа для хранения Git-репозиториев. (М0-06)
- **Glossary** [глос-са-рий] — словарь терминов. (М0-07)
### Буква I
- **Integration-тесты** Проверка того, как компоненты работают вместе
- **.includes** возвращает true, если подстрока найдена.
### Буква K
- **Kanban** To Do (Надо сделать), In Progress (В работе), Done
(Сделано). Задачи (стикеры) двигаются слева направо
### Буква L
- **log** - проверка всех комитов
### Буква M
- **Markdown** [марк-даун] — язык разметки текста (заголовки, списки). (М0-02)
- **MV** (move) — команда терминала для перемещения или переименования файлов. (М0-03)
### Буква N
- **Node.js** [ноуд джей-эс] — среда выполнения JavaScript вне браузера. (М0-04)
- **NPM** [э-н-пи-эм] — Node Package Manager, менеджер пакетов. (М0-04)
- **Non-functional Testing** Как быстро работает или «Удобно ли пользоваться?»
### Буква P
- **PWD** (print working directory) — команда терминала, показывающая текущую папку. (М0-01)
- **push** - отправить в облако
- **pull** - взять из облака
### Буква R
- **Repository** [репозиторий] — хранилище кода и его истории. (М0-05)
- **RM** (remove) — команда терминала для удаления. (М0-03)
- **Regression Testing** разработчик
починил кнопку «Вход», тест проверяет, что кнопка «Выход» всё ещё работает.
### Буква S
- **SSH** [эс-эс-эйч] — безопасный протокол для связи с GitHub. (М0-06)
- **SDLC** (Software Development Life Cycle) Жизненный цикл разработки
программного обеспечения
- **STLC** (Software Testing Life Cycle) Жизненный цикл тестирования
- **Scrum** Спринты (обычно 2 недели)
- **Smoke Testing** быстрый тест после сборки
- **Sanity Testing** Узкое тестирование конкретной фичи после её исправления
- **setTimeout(функция, миллисекунды) — выполняет код с задержкой**
### Буква T
- **Touch** [тач] — команда терминала для создания пустого файла. (М0-03)
- **Test Pyramid** много быстрых тестов внизу, мало медленных тестов наверху
- **Test Design** процесс
превращения требований в набор эффективных и достаточных тестовых сценариев
### Буква U
- **Unit-тесты** Модульные тесты
