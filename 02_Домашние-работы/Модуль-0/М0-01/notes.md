# Мои заметки по курсу QA Automation

## М0-01: Первый терминал
- Я научился использовать команду `pwd` (показывает папку).
- Команда `ls` показывает список файлов.
- Команда `mkdir` создаёт папку.
- Команда `cd` перемещает между папками.
- **Главное правило:** в терминале нет новостей — это хорошие новости.

## М0-02: Настройка VS Code
- Я установил тему и размер шрифта 16.
- Включил автосохранение (`"files.autoSave": "onFocusChange"`).
- Понял, что **JSON** — это формат `"ключ": "значение"`.

## Построчный разбор:

# Мои заметки... — один символ # делает текст огромным заголовком (как H1 в Word).

## М0-01... — два символа ## делают заголовок поменьше (как H2).

- Я научился... — дефис и пробел делают маркированный список (буллиты).

`pwd` — обратные кавычки (клавиша Ё на клавиатуре) делают текст «кодом» (моноширинный шрифт с серым фоном).

**Главное правило:** — две звёздочки с двух сторон делают текст жирным.
