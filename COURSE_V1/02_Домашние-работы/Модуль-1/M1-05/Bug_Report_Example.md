# [Избранное] Ошибка 403 при попытке добавить фильм в избранное
**Severity:** Major
**Priority:** High
**Environment:** Windows 11, Google Chrome (версия 119), Production
**Автор:** Даниил
## Шаги воспроизведения
1. Авторизоваться под тестовым пользователем `test_user@example.com`.
2. Перейти на страницу любого фильма (например, `/movie/123`).
3. Нажать на иконку "Сердечко" (Добавить в избранное).
## Фактический результат
Появляется красная плашка с текстом: "Ошибка 403. Доступ запрещен". Фильм не 
добавляется в список избранного. В DevTools (Network) видно, что запрос POST 
/api/favorites возвращает 403.
## Ожидаемый результат
Фильм успешно добавляется в "Избранное". Иконка "Сердечко" становится закрашенной. 
Статус-код ответа сервера: 200 OK.
