# Контрольные вопросы
1. Основной вопрос: В чём главное отличие Set от обычного массива []? В каких двух
случаях автотестировщик выберет Set?
- не имеет повторений. когда нужно получить список без дублей и когда в этом списке нужно быстрой найти совпадения
2. Вопрос на понимание: В чём главное отличие Map от обычного объекта {}? Каким
свойством проверяется количество элементов в Map и Set? 
- В мап ключ может принимать любой вид типа, через .size
3. Вопрос на терминологию: Что такое деструктуризация? В чём ключевая разница между
деструктуризацией объекта const { a, b } = obj и массива const [a, b] = arr
(подсказка: где важен порядок переменных, а где имена)?
- это распаковка объекта на константы, в объекте важны имена в массиве порядок
4. Вопрос с подвохом (на М2-А-03 и Set): У вас есть массив чисел с дублями const nums
= [1, 2, 2, 3, 3, 3]. Напишите ровно одну строчку кода (используя Set и оператор
Spread ...), которая превратит его в массив уникальных чисел [1, 2, 3].
- const numses = [...new Set(nums)] 
5. Вопрос с подвохом (на М2-А-02 — Ссылки в Set): Что выведет код: const s = new
Set(); s.add({ id: 1 }); s.add({ id: 1 }); console.log(s.size); — число 1 или 2?
Почему? 
- 2 из за того что добавленно как два разных объекта
6. Вопрос на «снежный ком» (Мостик в API Модуль 6): Представьте, что сервер вернул
вам массив из 50 пользователей users (у каждого есть поле email: string). Как за одну-
две строчки кода с помощью .map() и new Set() проверить, что у всех 50 пользователей
email-адреса уникальны (нет ни одного дубля)? (Подсказка: сравните users.length и
.size у Set). 
- const emails = new Set(users.map((u) => u.email)).size === users.length
