## М0-01. Терминал и структура проекта
Терминал — окно, оболочка — программа внутри.
На Windows: PowerShell (современная) и cmd (старая).
Примеры из интернета с $, sudo, -p — это bash,
они не работают в PowerShell.
Мои команды:
- Где я .................. Get-Location (коротко: pwd)
- Что вокруг ............. Get-ChildItem (коротко: ls, dir)
- Перейти ................ Set-Location (коротко: cd)
- Создать папки .......... New-Item -ItemType Directory -Force -Path "a","b"
- Создать файл ........... New-Item -ItemType File -Path "путь\файл.md"
- Проверить существование . Test-Path -PathType Container "папка"
- Примерка удаления ...... Remove-Item -Recurse -WhatIf "папка"
Ловушки:
1. mkdir -p — нет в PowerShell, вместо -p работает -Force.
2. Несколько путей — через запятую, иначе вторая
папка создастся ВНУТРИ первой.
3. Пробел в имени — кавычки.
4. cd и другой диск: в cmd нужен /d, в PowerShell не нужен.
5. Перед удалением — Get-Location. Всегда.
