## М0-01. Терминал и структура проекта
Терминал — окно, оболочка — программа внутри.
На Windows: PowerShell (современная) и cmd (старая).
Примеры из интернета с $, sudo, -p — это bash,
они не работают в PowerShell.
Мои команды:
- Где я .................. Get-Location (коротко: pwd)
- Что вокруг ............. Get-ChildItem (коротко: ls, dir)
- Перейти ................ Set-Location (коротко: cd)
- Создать папки .......... New-Item -ItemType Directory -Force -Path "a","b"
- Создать файл ........... New-Item -ItemType File -Path "путь\файл.md"
- Проверить существование . Test-Path -PathType Container "папка"
- Примерка удаления ...... Remove-Item -Recurse -WhatIf "папка"
Ловушки:
1. mkdir -p — нет в PowerShell, вместо -p работает -Force.
2. Несколько путей — через запятую, иначе вторая
папка создастся ВНУТРИ первой.
3. Пробел в имени — кавычки.
4. cd и другой диск: в cmd нужен /d, в PowerShell не нужен.
5. Перед удалением — Get-Location. Всегда.

## М0-02. VS Code под QA
Открывать ПАПКУ (File > Open Folder), не файл:
иначе терминал и расширения не видят проект.
Два уровня настроек:
- User ....... %APPDATA%\Code\User\settings.json (все проекты)
- Workspace ... проект\.vscode\settings.json (только проект, в git)
Workspace перекрывает User.
Мои настройки проекта (13 штук), главные:
- editor.formatOnSave: true
- editor.defaultFormatter: esbenp.prettier-vscode <- имя РАСШИРЕНИЯ
- editor.tabSize: 2, insertSpaces: true
- files.encoding: utf8, files.eol: "\n" (UTF-8 + LF = одинаково везде)
- terminal.integrated.defaultProfile.windows: PowerShell
- files.trimTrailingWhitespace / insertFinalNewline: true
Ловушки:
1. Комментарии в settings.json: VS Code поймёт, ConvertFrom-Json упадёт.
2. formatOnSave без установленного Prettier = тишина.
3. Смена профиля терминала не перезапускает старый терминал.
4. Кракозябры: Reopen with Encoding, затем Save with Encoding > UTF-8.
5. "Изменён весь файл" = CRLF vs LF.
6. Больше расширений - больше конфликтов. Список живет в .vscode\extensions.json.
Проверка: 00_Мета\проверка-vscode.ps1 -> "Настройки в порядке: 4 из 4".
