# QA-Learning-2026

Учебный проект по QA Automation: от терминала до автотестов на Playwright.
Здесь я учусь с нуля и фиксирую каждый шаг в git.

## Структура

- `COURSE_V1` - старый курс, генерирован на дипсике + гемини.
- `COURSE_V2/00_Мета` — конспект, проверочные скрипты
- `COURSE_V2/01_Лекции` — материалы уроков
- `COURSE_V2/02_Домашние-работы` — выполненные задания по модулям
- `COURSE_V2/03_Пет-проект` — итоговый проек

## Как запустить

Нужен Node.js

```bash
  npm install
  npm start
```
